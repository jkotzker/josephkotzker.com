# Critique of 023 — 019 with the Elsewhere links as icon plus text, like the nav

Date: 2026-10-01

Read from source; the rendered page was not inspected (page tools cannot read local files). Contrast ratios computed from the declared colours (WCAG 2 relative luminance).

## Slop tells

- (`body`, `font: … ui-serif, "Iowan Old Style", "Charter", Georgia, serif`) The body face is the system serif stack — the rubric's "system stack when typography was supposed to carry the design". Mitigation: Joseph chose it explicitly ("I do like the simpler typefaces of 001 and 002"), so it is a decision, not a default. The residual risk is that the page renders as New York on Apple devices and Georgia elsewhere, so the site's one typographic voice differs by platform.
- (`:root` colours) Joseph describes the scheme as "the blues and the grays", but the greys are warm: muted `#6f6b64` and rules `#e6e2da` lean brown, and the background `#fdfcfa` is an off-white with a yellow cast. The blue link is the only cool value. Not the "beige palette chosen by nobody" tell — it was chosen in 001 — but the description and the values disagree, which matters at convergence when these become named tokens.

## Coherence breaks

- (`nav.side`, section links vs Elsewhere links) Two icon languages in one list: the section links use Lucide outline icons (2px stroke, no fill), the Elsewhere links use Simple Icons filled brand marks. At 1em they differ in visual weight — the brand marks read as solid blobs beside outlined pictograms. This is the "component language" clash the source site was criticised for, at small scale. Options: outline versions of the brand marks, filled versions of the section icons, or no icons on one of the two groups.
- (`nav.side .label`) "Elsewhere" is the only uppercase, letter-spaced text on the page — a third typographic treatment beside the serif body and bold headings. Small, but it reads as a dashboard label inside a document.
- (footer vs `nav.side`) RSS appears twice — in the nav with an icon and in the footer as plain text.
- (`#podcast` section) The Podcast section repeats the bio's sentence about In Reverse and Zach Kotzker; on a page this short the duplication is visible.

## Placeholder copy

- (`#writing`, `#projects`) "Sample date", "Sample post title, for layout", "Sample project — one line on what it does". Expected at this stage — copy is Part 3 — but it means the list rhythm (title lengths, date format) is unjudged.
- (`.headshot`) Placeholder glyph; the real photo will change the top of the page's weight more than anything else on it.
- (nav Résumé, nav/footer RSS) `href="#"`.

## Basic accessibility

- Contrast passes WCAG AA for all running text: ink 16.6:1 light / 14.5:1 dark, muted 5.2 / 6.1, link 7.6 / 8.5.
- (`nav.side .label`) "Elsewhere" is muted at `opacity: .75`: 3.1:1 light, 3.9:1 dark — below 4.5:1 for text of this size (~12.8px).
- (`.headshot` glyph) Muted on the rule colour: 4.1:1 light. Placeholder only; moot once a photo replaces it.
- (`nav.side a`, list links) Target height ~29px for nav links (15.2px × line-height 1.9) and ~30px for list links — under the ~40px guideline. Nav links are full-width blocks, so the horizontal dimension is fine.
- (`a`, `nav.side a`) No `:focus-visible` style is defined; focus relies on the browser's default outline. Nav links remove the underline and change only colour on hover, so keyboard focus has no designed state.
- (`nav.side`, `position: fixed`) Eleven items plus the label at `top: 12vh`, roughly 360px tall, with no overflow handling: on a short window (a landscape laptop with the browser zoomed, a phone in landscape above the 64rem breakpoint is unlikely but a short desktop window is not) the bottom of the list is cut off and cannot be scrolled to.
- No `<main>` landmark around the column; headings are correct (one `h1`, then `h2`s).

## The one thing to keep

The quiet fixed sidebar beside a single centred serif column (023 `nav.side` + `body` at a 34rem measure): the sidebar is set entirely in the muted colour at a smaller size, so it navigates without ever competing with the column — the column stays the page.
